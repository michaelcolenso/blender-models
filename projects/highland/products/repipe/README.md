# Highland: proposed unit-by-unit repipe sequence

The owner selected **new supply routes installed alongside the existing system, followed by one-unit-at-a-time cutover**. This animation illustrates that strategy with the Unit 107 drawing study and its five-fixture bathroom pilot. It is a proposal for discussion, not a contractor-approved means-and-methods plan or a verified survey of installed piping.

## What moves

1. A representative floor-protection area appears at the bathroom pilot.
2. New distribution routes grow alongside the gray drawing reference.
3. Branches extend toward fixtures; nine pilot tie points remain disconnected.
4. The animation pauses at a testing/acceptance gate. It does not report a passed test.
5. During the scheduled cutover, nine ties switch in five fixture groups. The displayed unit boundary must be established in the field; this model does not prove independent unit isolation.
6. Service verification follows. Moving color markers indicate the sequence, not a flow or temperature simulation.
7. Only pilot terminal references fade. Shared mains stay visible because their other users are not established. The sequence then points to the next unit.

The illustration includes 37 concept routes reused from the Unit 107 domestic-water topology. Only the bathroom's nine fixture connections are explicit in the cutover demonstration. Other Unit 107 connections, shared building risers, plant interfaces and subsequent units need separate design and isolation planning. The animation is not evidence that those connections are resolved.

## Separate proposal and reference

`repipe-strategy.json` is the sequencing specification, generated by `prepare.py`. It records the reference-spec hash, owner-selected strategy, phase timing, route IDs, nine fixture ports and every assumption. The drawing-reference model remains unchanged. The viewer places reference and proposed geometry in separate scene groups; it does not relabel the reference as a verified as-built.

Every proposed route, tie point and protection graphic is **assumed**. Reference topology is reused to explain the sequence, not selected as final replacement routing. New paths are separated by **0.25 m for graphical legibility only**, not a proposed construction offset or verified clearance. Nominal diameters are enlarged 1.5× with a minimum display radius of 10 mm. Pipe sizes, materials, fittings, isolation points, access openings, protection/staging/egress limits and shutdown duration remain to be established. There are no construction quantities, test-pressure prescriptions or promises of uninterrupted service.

P4.01 supplies the underlying Unit A/107 reference. A2.03 and A3.11 support the prior grid calibration and floor datums. The original plumbing PDF annotations identify systems, risers and a floor-protection annotation on another sheet; no documented repipe method was found in the reviewed annotations/model notes. These documents are source evidence, not instructions to perform work.

## Reproduce

Use the Three.js/esbuild versions pinned in `../highland-water/package.json`; Playwright, Chromium and FFmpeg are also required. The existing `build/highland-water/unit.glb` must be present.

```bash
python projects/highland/products/repipe/prepare.py
# Run with the pinned esbuild and Three.js dependencies available:
esbuild projects/highland/products/repipe/app.js --bundle --minify --format=iife --outfile=projects/highland/products/repipe/app.bundle.js
python projects/highland/products/repipe/package.py
python -m http.server 8881 --bind 127.0.0.1 --directory build/highland-repipe
# In another shell:
node projects/highland/products/repipe/render.cjs http://127.0.0.1:8881/Highland-repipe-sequence.html build/highland-repipe
```

The standalone HTML offers Play/Pause, a time slider, and seven phase buttons. The 32-second video is 1280×720 at 24 fps. Add `--review-only` to run the checks and capture review stills without encoding a video.

## Checks and limits

The preparation step checks unique route IDs, five cold/four hot pilot ports, agreement of those ports with reference route endpoints, and testing before cutover. Browser checks confirm zero completed ties before cutover, nine completed ties afterward, all 37 proposed routes present at the end, seven-phase navigation, playback and no mobile horizontal overflow. These checks verify presentation sequencing, not actual isolation, hydraulic performance, whole-model clash freedom or construction readiness.

Phase stills and encoded-video samples are inspected before delivery. The HTML, MP4, animated preview and validation record are in `projects/highland/deliverables/repipe/`.
