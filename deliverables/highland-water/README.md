**Unit 107 plan XY is provisional; building floor datums are documented. Pipe heights, building stack XY and fixture/equipment envelopes remain assumed.** Source pipe sizes and connection patterns are recorded separately from geometry assumptions. Use the **Bathroom** button for the close-up. The model covers domestic water; sanitary, vent and gas are not included. It is a working model study, not an as-built or a dimensionally verified owner presentation. See the review PDF's final page for the next required dimensions and unresolved connections.

The previous [sheet-stack tour](../highland/) is superseded as the approach to this task. No replacement animation is claimed complete; the pipe trace and dimensions come first.
