# Shared HDRIs (CC0)

The HDRI is **Kloofendal 48d Partly Cloudy (Pure Sky)** from [Poly Haven](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky), released under [CC0](https://polyhaven.com/license). `sources.json` records the original URL and verified upstream MD5 plus SHA-256. The builder packs this image into the `.blend`; opening the file requires no network or add-on.

Used by the Highland archviz/cinema builds (`projects/highland/products/walkthrough/archviz.py`) and the Meydenbauer realism model. Leaves, small branches, curtains, apartment back panels, furniture, and abstract artwork are original deterministic procedural geometry in `archviz.py`. They are illustrative presentation assets. No Botaniq, Geo-Scatter, BlenderKit, manufacturer IES data, or paid asset libraries are bundled.
